# Creative ERP Release Notes

# Version 1.1.0 – Expanded Enterprise Capabilities

**Release Date**: September 2026  
**Status**: Stable & Active  

---

# 1. Overview

Version 1.1.0 introduces major enhancements to Creative ERP, expanding operational site management, material issuance workflows, labor expense tracking, fixed asset lifecycle management, and financial accounting auto-posting capabilities.

---

# 2. What's New in Version 1.1.0

### 📦 Site Material Request & Material Issuance System
- **Site Request Workflow**: Site engineers can request construction materials directly for specific projects and tasks.
- **Request Conversion**: Approved material requests can be converted into Purchase Requisitions or issued directly from warehouse stock.
- **Direct Material Issuance**: Material issues draw stock directly from a designated warehouse, update stock levels, log `WarehouseMovement` records, and update project actual costs.

### 💰 Project Expenses & Worker Salaries Tracking
- **Expense Categorization**: Form request and model scopes now classify project expenses into Direct Site Expenses vs. Labor Costs / Worker Salaries.
- **Cost Rollup**: Expenses automatically aggregate into `Project::actual_cost` for real-time budget variance tracking.

### 🛒 Goods Receipts (GRN) & 3-Way Match
- **Physical Goods Receiving**: Receive PO items into specific warehouse zones and bins.
- **Automated Financial Posting Engine**: Goods Receipt creation automatically generates double-entry General Ledger vouchers (Debit Inventory Asset, Credit Accounts Payable / Accrued PO Liability).

### 🏛️ Double-Entry Financial Engine & Accounting Period Locks
- **Chart of Accounts & General Ledger**: Complete ledger system supporting debit/credit balance validation.
- **Fiscal Years & Monthly Period Closing**: Monthly period locking blocks backdated journal voucher creation or historical posting.

### 🚜 Fixed Asset Management & Automated Depreciation
- **Asset Life Cycle**: Asset registration, assignments to employees/projects, location transfers, scheduled maintenance, and disposal workflows.
- **Depreciation Generator**: Automated monthly depreciation calculations (Straight Line, Declining Balance) with direct General Ledger posting.

### 🏭 Advanced Warehouse Management (WMS)
- **Bin-Level Tracking**: Storage location mapping across Warehouses, Zones, and Bins.
- **WMS Tasks**: Support for Put-Away, Picking lists, Packing slips, Customer Returns, and Cycle Counts.

# 3. Upgrade & Migration Instructions

To upgrade an existing installation to Version 1.1.0:

```bash
# 1. Pull latest code
git pull origin main

# 2. Update dependencies
composer install
npm install

# 3. Run new database migrations
php artisan migrate

# 4. Clear & recompile cached configurations
php artisan config:clear
php artisan route:clear
php artisan view:clear

# 5. Compile frontend assets
npm run build
```
